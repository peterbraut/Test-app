# Test App

En moderne webapp.

## Mappestruktur

```
test-app/
├── public/          # Filer som vises direkte i nettleseren
│   └── index.html   # Hovedsiden
├── src/             # Kildekode
│   ├── components/  # Gjenbrukbare UI-komponenter
│   ├── pages/       # Sider i appen
│   ├── styles/      # CSS-stiler
│   └── assets/      # Bilder, ikoner, fonter
│       └── images/  # Bildefiler
└── docs/            # Dokumentasjon
```

## Kom i gang

Åpne `public/index.html` i en nettleser for å se appen.
